# Nexus 外设电量中心

[下载最新正式版](https://github.com/1245047209-dotcom/1/releases/latest)

Windows 10/11 x64 桌面外设电量工具，正式安装包包含运行环境。

v73.5 在 Windows 11 22H2 及以上使用原生主窗口。浅色和深色在聚焦与失焦时都保留实时毛玻璃，深色模式采用更深的底色。

发布附件包含 Windows 安装包、完整源码 ZIP，以及各自的 SHA-256 校验文件。覆盖安装保留设备列表、设置和耗电记录。

## 源代码与构建

`app/` 保存程序源码、测试及新增界面资源。原有产品图库和 Python 运行环境从 SHA-256 固定的上一版安装包重建。完整源码可从 Releases 下载。

Windows 发布工作流会检查全部回归测试、原生主窗口启动、安装后的文件哈希和从 v73.4 覆盖安装时的用户数据保留情况，全部通过后才发布新版本。

开发与后续发布方法见 [PUBLISHING.md](PUBLISHING.md)。

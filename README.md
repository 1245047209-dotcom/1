# Nexus 外设电量中心

[下载最新正式版](https://github.com/1245047209-dotcom/1/releases/latest)

Windows 10/11 x64 桌面外设电量工具，正式安装包包含运行环境。

v73 重做主窗口。设备卡片纵向排列，窗口高度随设备数量调整，顶部可切换跟随系统、浅色和深色。

发布附件包含 Windows 安装包、完整源码 ZIP，以及各自的 SHA-256 校验文件。覆盖安装保留设备列表、设置和耗电记录。

## 源代码与构建

`app/` 保存程序源码、测试及新增界面资源。原有产品图库和 Python 运行环境从 SHA-256 固定的 v72 安装包重建；需要直接运行的完整源码请下载 Releases 中的源码 ZIP。

Windows 发布工作流会检查全部回归测试、隐藏窗口布局、安装后的源文件哈希和用户数据保留情况，全部通过后才发布新版本。构建不使用个人令牌，也不上传本机设备配置或历史记录。

开发与后续发布方法见 [PUBLISHING.md](PUBLISHING.md)。

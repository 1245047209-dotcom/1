# Logitech G304 / G305 LIGHTSPEED（v61）

适配接收器 `046D:C53F`。用户已确认目标设备为黑色 G304。
该接收器属于 G304/G305 系列；软件通过 HID++ `0x0005 DEVICE_NAME` 查询配对鼠标名称，识别后显示 G304 或 G305，并保存到原设备条目。
旧版的 LIGHTSPEED Receiver 条目自动识别为该系列，无需删除重加；未读取到鼠标名称时显示系列名称。

## 电量语义

- 使用 HID++ `0x0000 GetFeature` 动态取得 `0x1000 BATTERY_STATUS` 的索引，再调用函数 0 读取电量。
- 返回的前三个字节依次为当前电量档、下一档、电池状态。状态 0 是放电；G304/G305 使用 AA 电池，其他充电或异常状态不作为有效电量样本。
- 当前档 0 表示未提供有效电量，显示 `--`。大于 100 的值、超时、异常回复均不会显示为有效百分比。
- 界面注明“设备分档上报 · AA 电池”。例如公开实机记录 G304 为 90%，下一档 50%；G305 为 50%，下一档 30%。数值长期不变不一定是读取卡住，不能理解为精确到 1%。
- 不使用 PRO WIRELESS 的 `0x1001` 电压曲线，不推算剩余小时，不伪造充电状态。刷新失败会清除本轮百分比，保留上次成功读取时间。
- 只访问所选物理接收器的 HID 路径，使用厂商定义的 20 字节 HID++ 长报文接口；不写键鼠输入接口，不进行配对、DPI 或配置修改。

## 使用及验证范围

安装 v61 后插入接收器，打开鼠标电源，移动鼠标后点击刷新。已加入的旧条目可直接使用；新设备通过“搜索设备”加入。
鼠标休眠或关机时可能不响应，唤醒后重试。接口占用时退出占用它的程序后重试。
本机没有连接 G304 实物：已验证公开协议、有效及异常报文、型号识别、物理设备隔离、旧设备记录迁移和双视图图片；目标电脑实际电量仍需朋友安装后确认。
朋友截图为 v57，尚无在线更新功能，需手动安装一次 v61；此后可从软件设置中检查更新。

# GPU 动画加速（v70）

设置与偏好中的「GPU 动画加速」默认开启，保存后生效。设备详情和全部设备之间的切换，使用 Windows Direct2D 硬件渲染目标合成整块内容的淡入淡出和平移；文字、产品图、设备协议及最终布局沿用 v68。

每个切换阶段只准备一次画面并上传到显存，播放期间由 GPU 连续混合透明度和平移，避免逐帧生成 Tk 图片。高精度计时仍只在动画播放期间使用。动画结束即销毁临时窗口和画面纹理，空闲时没有持续刷新。

首次硬件初始化在后台进行，使用多线程 Direct2D 工厂；后台不访问 Tk 对象。初始化尚未完成、显卡不支持硬件目标、捕获/上传/呈现失败时，使用原有 Tk 渲染。关闭设置中的开关可使用兼容方式；关闭再开启也可重新尝试硬件初始化。未使用软件 Direct2D 目标冒充 GPU 加速。

这是视图切换动画的硬件加速，并非将全部界面、字体排版或布局构建迁移到 GPU。动画仍以 60 Hz 调度，不承诺实际屏幕始终保持 60 FPS；繁忙的系统、显卡驱动及首次图片/字体加载仍可能影响流畅度。

本机真实 Tk 窗口完成硬件渲染、连续切换、快速中断与软件回退验证。截图检查工具当前不可用，未将人工视觉验收记为完成。

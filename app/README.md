# Nexus 外设电量中心 · v73.5

## 运行

Windows 10/11 x64。正式安装包自带 Python 3.12 与 Tkinter。完整源码 ZIP 需要 Python 3.12 x64（含 Tcl/Tk），无需第三方 Python 包。

在完整源码目录运行：

```powershell
py -3.12 my_devices.py
py -3.12 tray_app.py
py -3.12 -m unittest discover -s tests
```

也可使用附带的启动 BAT；若复制了现有便携版的 runtime 文件夹，会优先使用它。源码包不附个人设备列表，首次运行可通过“搜索设备”加入外设。

## v73.1（v73-iOS 界面改版）

- 配色改用 iOS 系统色：浅色分组背景 #F2F2F7 / 白色卡片，深色纯黑背景 / #1C1C1E 卡片；强调色为 iOS 系统蓝，电量圆环为系统绿，20% 及以下变为系统红。
- 字体改用系统自带的 Microsoft YaHei UI（有真正的粗体），百分比使用 Segoe UI Semibold，图标使用 Segoe Fluent Icons（Windows 10 为 Segoe MDL2 Assets）。不再注册附带的思源黑体。
- 主窗口加入毛玻璃背景（`glass.py`，原理同 Windows 11 云母效果）：取桌面壁纸中窗口背后的部分，模糊后按浅色 / 深色主题着色作为背景，电池小组件和设备列表卡片是更白（深色时更深）的一层玻璃，边缘有一圈约 1 像素的高光描边，上亮下淡（深色模式更含蓄），像光从上方照在玻璃上；按钮背后也透出同样的背景。移动窗口或滚动列表后约 0.15 秒重新取样；壁纸、壁纸填充方式或所在显示器变化时自动更新。着色会保证文字对比度。Tk 无法透视窗口，所以只透出桌面壁纸，不透出背后的其他窗口。可在「设置 → 外观 → 毛玻璃背景」关闭；读不到壁纸时自动改用桌面纯色或普通背景。设置、添加设备和设备详情保持不透明（与 iOS 的表单和弹出面板一致）。
- 主窗口默认尺寸按 iOS 视觉稿调整为窄而高：默认宽 484（最窄 440），3 台设备时客户区约 425×530 像素；圆环、列表行、字号和间距同步放大，按钮移到大标题同一行。圆环下方按类型标注「键盘 / 鼠标 / 耳机 / 充电仓」，同类设备有两台以上时改用型号名；有耳机时列表下方注明「耳机显示左右耳中较低的一侧」。
- 主窗口改为 iOS 大标题「设备」，下方一行摘要（「N 台需要充电」或「在线数」，附更新时间）；右上角为「刷新」胶囊按钮和圆形「添加设备」「设置」按钮。底栏与顶部主题切换已移除（主题在「设置 → 外观」）。
- 顶部是仿 iOS「电池」小组件：每台设备一个电量圆环，环内为设备图标；耳机拆成「耳机」（取两耳中较低的一侧）和「充电仓」两个圆环；充电时右上角有闪电标记。每行 4 个，超过换行。
- 下方为 iOS 分组列表「我的设备」：缩略图、名称、状态与读数时间、电量和箭头。读数时间显示为「刚刚」「3 分钟前」「2 小时前」，每秒自动更新；读取失败时显示「上次读取 10 分钟前」。「查看设备信息」里仍显示具体时刻。左键点击一行查看设备信息，右键打开菜单（查看设备信息、移除设备）。
- 圆环、圆角卡片按屏幕实际像素渲染（`ios_art.py`），边缘抗锯齿；读数变化时只替换圆环图片和文字，不重排。
- 「查看设备信息」改为 iOS 底部面板（`device_sheet.py`），替代原来的系统消息框：从窗口底部滑出，顶部露出一条变暗的主窗口，点它、点「完成」或按 Esc 关闭。面板里是产品图、大号电量（20% 及以下为红色）和状态，下面是连接方式、供电状态、读数来源、读取时间、续航（F87 Pro）、硬件 ID；耳机另列左耳、右耳、充电仓的电量和更新时间。底部有「立即读取」和「移除设备」（需再点一次确认）。读数变化时面板实时更新；内容比窗口高时在面板内滚动，主窗口大小不变（以前会临时加高窗口，加高时整个主窗口重画，是弹出动画中那一帧约 80 ms 卡顿的来源）。面板在弹出前一次排好版、画好背景，滑出过程中只移动位置（60 Hz 节拍），加高窗口时不重绘主窗口，动画期间暂停毛玻璃取样；滑动时直接调用 Windows 的 SetWindowPos 移动面板，并且面板里的所有图片都是不透明的（圆角预先与背景色混合）。Tk 在 Windows 上绘制半透明图片时要从屏幕读回像素，会被桌面合成器卡住，这是弹出卡顿的主要原因；设置页、添加设备的分组卡片和细滚动条也同样改为不透明，滚动更顺。
- 「添加设备」改为 iOS 样式：顶部「重新搜索 / 添加设备 / 完成」，下面是「2.4G / USB」「蓝牙设备」分段控件（支持左右方向键；只有用 Tab 或方向键切到它时才显示蓝色焦点框，鼠标点击和窗口打开时不显示）。结果为分组列表，每行有产品图、名称、硬件 ID 与状态，右侧是「添加」按钮；已添加的显示「✓ 已添加」，无法确认能否读取电量的 USB 设备显示「仍然添加」。添加后窗口保持打开，可以连续添加，结果显示在列表下方，失败原因也显示在这里，不再弹出系统对话框。
- 点开一行显示识别信息和「复制设备信息」；狼蛛键盘还可以从菜单里更改型号和配色（配色带色块），已添加的设备改完后按钮变为「更新」。右键一行也能复制设备信息。「显示待确认的 USB 设备」开关移到列表下方。
- 设置页改为 iOS 设置样式：顶部「取消 / 设置 / 完成」；分组列表「外观」「刷新」「通知与系统」「软件更新」「工具」，每项左侧是彩色方块图标；开关改为 iOS 样式（51×31，圆形滑块）；刷新间隔显示为灰色数值和上下箭头。
- 外观直接在设置首页修改：浅色 / 深色预览加单选圆点，「自动」开关表示跟随 Windows。选择后主窗口立即预览，点「完成」保存，点「取消」、关闭窗口或按 Esc 会还原。原「外观」子页面和 Liquid Glass 滑块已移除（iOS 版主窗口不使用玻璃材质，配置项保留不动）。

- 设置页与搜索窗口的圆角卡片改为抗锯齿绘制。
- 主窗口、设置页和更新说明的滚动条改为 iOS 式细滚动指示条：无轨道和箭头，浅色 / 深色自动配色，悬停或拖动时加粗；内容放得下时隐藏。

## 电量与设备支持

PRO WIRELESS 使用 HID++ 直接读取电压和状态，百分比来自电压换算，无需 G HUB。G304/G305 使用设备分档上报。Beats Studio Buds 使用已配对设备的原生查询，分别显示左耳、右耳和仓的设备上报值，不可读时显示 --。

狼蛛型号与协议验证范围见《AULA机械键盘支持清单.md》，V2D 和 G304 另有协议说明。不同设备的支持程度依协议和实物验证情况而定。

## 代码结构

- `my_devices.py` / `my_devices.pyw`：主界面及 GUI 入口。
- `device_navigation.py` / `view_switcher.py`：导航控件与动画。
- `frame_pacer.py` / `ui_motion.py` / `staged_canvas.py`：帧调度、透明度缓存与分批场景提交。
- `query_coordinator.py` / `device_readers.py` / `reading_ui.py`：查询协调、读数模型与局部刷新。
- `receiver_search.py` / `receiver_scan.py` / `saved_devices.py`：搜索、识别与设备管理。
- `logitech_*` / `aula_*` / `beats_*`：对应设备读取实现。
- `tray_app.py` / `tray_common.py`：后台托盘与偏好设置。
- `update_client.py` / `update_ui.py` / `app_dialogs.py`：GitHub 在线更新和设置面板。
- `assets/`：产品图库和 UI 资源；保留原有来源记录与许可证。
- `tools/`：资源生成脚本；`tests/`：回归测试。

GitHub 仓库中的 app 目录是构建覆盖层；完整源码 ZIP 含有全部产品图和资源。覆盖安装保留设备、偏好和耗电记录。不要将个人 JSON、日志、锁文件或 PID 文件提交到仓库。

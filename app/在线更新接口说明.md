# Nexus v59 在线更新接口

更新仓库：https://github.com/1245047209-dotcom/1

## 客户端

- 软件启动后后台检查，最多每 6 小时自动请求一次。
- 主界面关闭、托盘运行时也可检查新版本并显示通知。
- 设置窗口和开始菜单均有“检查更新”入口，手动检查不受时间间隔限制。
- 显示版本、更新说明、下载进度；用户可稍后处理、忽略某版本或关闭自动检查。
- 仅比较正式版本，支持 `v59`、`v59.1`、`v59.1.0`，不会降级安装。
- 只访问 GitHub HTTPS 更新地址，不上传设备列表或电量历史，不在客户端放入发布令牌。
- 下载校验通过后需用户点击“立即安装”并确认，才打开安装向导。
- 使用同一安装目录覆盖升级，保留设备、历史、设置及自动更新偏好。
- v58.1 和更早的安装包需要手动安装一次 v59，之后才支持在线更新。

## 版本检查 API

```http
GET https://api.github.com/repos/1245047209-dotcom/1/releases/latest
Accept: application/vnd.github+json
X-GitHub-Api-Version: 2022-11-28
```

公开仓库无需登录。客户端使用 `tag_name`、`body`、`draft`、`prerelease` 及 `assets`。
仓库尚无 Release 时返回 404，客户端显示“没有发现更新”，不会影响电量读取。
网络超时或 GitHub 限流时可稍后手动重试。

官方接口文档：https://docs.github.com/en/rest/releases/releases#get-the-latest-release

## 发布约定

例如发布 v60，上传下列附件并将 Release 发布为正式版：

1. 标签 `v60`，更新说明填写在 Release 描述里。
2. 安装包 `Nexus-v60-Windows-x64-Setup.exe`。
3. 校验文件 `Nexus-v60-SHA256.txt`，内容格式如下：

```text
<安装包的64位SHA256十六进制值>  Nexus-v60-Windows-x64-Setup.exe
```

客户端优先使用 GitHub 资产接口中的 `digest: sha256:...`；若没有则下载上述校验文件。
缺少校验信息、下载长度不符、SHA-256 不符或不是 Windows PE 安装包时，不会启动安装。
不要勾选预发布；不需要另建 API 服务器，也不需要给用户发 GitHub Token。

官方资产接口文档：https://docs.github.com/en/rest/releases/assets

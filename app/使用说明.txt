使用方法
1. 双击桌面的“Nexus 外设电量中心”打开主界面。
2. 如需后台显示电量，打开开始菜单中的“Nexus 电量托盘”。
3. 狼蛛 F87 Pro 需通过 2.4G 接收器连接；主界面点击“搜索设备”添加支持的鼠标或已配对的蓝牙耳机。
4. 显示 -- 或未连接时，先确认设备型号受支持、设备已唤醒且接收器或蓝牙已连接。
5. 在“设置”里修改刷新间隔、低电量提醒和开机启动托盘。

当前适配：狼蛛 F87 Pro、AULA F87 Pro V2D、Logitech PRO WIRELESS、G304 / G305、Beats Studio Buds。
v61 新增 G304 / G305（046D:C53F）的型号查询、AA 分档电量与黑色产品图。
分档电量可能长期不变，不代表精确到 1%；鼠标需开机并唤醒后刷新。
本机未连接该型号实物，朋友电脑实际读数需安装后确认。
更多设备的识别和电量读取能力取决于具体型号与通信协议。

v58 新增 F87 Pro V2D（0C45:FEFE）2.4G 支持：
覆盖安装后，旧版已加入的设备会继续保留，型号显示为 AULA F87 Pro V2D。
如尚未加入，在“搜索设备”中加入该型号，切换 2.4G 模式并按键唤醒后刷新。
没有旧版 F87 Pro 在线时，托盘读取已加入的 F87 Pro V2D。
协议由公开实机验证项目提供依据，本机没有连接 V2D 实物，需目标设备确认最终读数。
若仍无电量，运行安装目录的 F87ProV2D读取诊断.bat，查看生成的诊断报告。

安装与卸载
默认安装在当前用户的 LocalAppData\Programs\NexusBatteryCenter，普通用户即可安装。
桌面快捷方式默认创建；开机启动由你在安装时或软件设置里选择。
可以在 Windows“已安装的应用”里卸载。
设备列表和电池历史存放在安装目录，卸载时保留这些个人数据。
请不要单独移动或删除安装目录里的 runtime 文件夹。

本分发包不含制作者的设备列表、历史记录和设置。
Python 及 Tcl/Tk 的许可随附在 runtime 目录中。
产品图片及商标归相应权利人，已有图片来源记录保留在 assets 目录。

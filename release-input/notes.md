Nexus v69：新增 Direct2D GPU 动画加速。

- 「设置与偏好」新增 GPU 动画加速开关，默认开启；视图切换时由显卡合成内容画面的淡入淡出和平移。
- 每个阶段只上传一次画面，不再在 GPU 路径中逐帧生成 CPU 透明度图片。
- 首次硬件初始化放到后台；未准备好、显卡不支持或渲染失败时，自动使用原有兼容方式。
- 动画停止后释放临时画面和窗口，空闲时不持续刷新。保留设备协议、电量读取协调、产品图片与 v68 布局。
- 261 项回归检查通过；真实 Windows 窗口验证正常切换、快速中断、计时回收及模拟硬件不可用后的自动回退。

本机绘制回调对照测试显示，GPU 路径开销明显降低；动画仍按 60 Hz 调度，不等于承诺始终 60 FPS，也不会加速全部 Tk 布局工作。首次显卡初始化已移到后台。

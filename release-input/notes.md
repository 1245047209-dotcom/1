## 启动与界面字体

- Windows 11 22H2 及以上，原生主窗口提前启动，备用界面的图片和动画按需加载。首次运行会生成多核 JIT 缓存，之后冷启动可利用缓存缩短等待。
- 从开始菜单打开「Nexus 快速打开」，关窗后可在 3 分钟内快速重开。此功能适用于支持原生主窗口的 Windows。在主窗口按 Ctrl+Q 可以立即退出。
- 在「设置 → 外观 → 界面字体」预览并选择系统默认字体或 Windows 已安装的阿里巴巴普惠体 2.0 字重。可从[阿里巴巴字体官网](https://www.alibabafonts.com/#/font)安装所需字重，再重新打开 Nexus。

支持 Windows 10/11 x64。可通过「设置 → 软件更新」获取新版。覆盖安装保留设备列表、设置和耗电记录。

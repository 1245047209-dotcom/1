设置页面改为左右两栏，同时展示偏好与软件更新。

- 左侧为“设置与偏好”：刷新间隔、自动刷新、开机启动托盘、低电量提醒，以及重建入口、测试提醒和保存按钮。
- 右侧完整显示“软件更新”：当前版本、更新状态、可滚动的更新说明、进度条、自动检查开关、发布记录及下载 / 安装按钮。
- 两部分始终固定在主窗口内，打开更新不再覆盖设置。托盘和开始菜单的更新入口也会进入同一面板。
- 检查更新、下载和忽略版本时保留未保存偏好；保存左侧设置后继续显示面板，方便同时查看更新。
- 保留 v62 的胶囊滑动开关与原有配色，以及 G304/G305 等设备支持。

Windows 10 / 11 x64，安装包包含运行环境。v59 及以上可从设置里在线更新；v58.1 及更早版本需要手动安装一次新版。覆盖安装保留设备列表和设置。
本安装包未做数字签名，Windows 可能显示“未知发布者”。

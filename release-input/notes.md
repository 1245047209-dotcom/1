Nexus v68：动画流畅度与首次切换性能优化。

- 将卡片悬停、视图切换和设备导航改为统一的 60 Hz 目标调度，以高精度时钟和绝对时间减少帧间隔累积；动画停止后释放高精度计时请求。
- 淡入淡出增加到 64 个透明度档位，按需生成图片帧并限制缓存大小；整组移动元素，只刷新变化的属性。
- 首次打开布局改为分批准备、统一显示，减少字体和图片加载集中阻塞界面的情况；连续切换会丢弃过期布局。
- 动画完成后使用局部数据刷新，避免再次整页重绘。保留 V67 导航、三设备总览、单设备布局和非线性过渡。
- 248 项回归检查通过，并验证布局坐标、快速中断切换及计时请求回收。

本机测试的动画回调间隔中位数由约 31 ms 降至 16.7 ms。这是调度测量，不等于屏幕实际始终保持 60 FPS；首次加载或系统繁忙时仍可能出现慢帧。

Windows 10 / 11 x64，安装包包含 Python 运行环境。覆盖安装保留设备列表、设置和耗电记录。
同时提供完整源代码 ZIP 和 SHA-256 校验文件。

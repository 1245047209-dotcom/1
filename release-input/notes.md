## 主窗口与外观

- 设备卡片改为从上到下排列，窗口高度随设备数量调整。设备较多时可滚动浏览，详情和移除操作集中在各卡片的「设备操作」菜单中。
- 主窗口顶部可切换「跟随系统」「浅色」和「深色」。深色主题为产品图片区域增加渐变描边，浅色主题采用简洁的卡片样式。
- 放大鼠标和耳机的产品图，并重绘设备连接状态标签，让圆角边缘在不同缩放比例下更平滑。

## 设置与搜索

- 设置和搜索窗口使用与主窗口一致的紧凑尺寸。
- 修复 USB 搜索失败后切换筛选会清除错误提示的问题。

覆盖安装会保留设备列表、设置和耗电记录。发布附件包含 Windows x64 安装包、完整源码 ZIP 和 SHA-256 校验文件。
